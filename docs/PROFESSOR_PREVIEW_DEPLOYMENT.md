# 教授預覽版部署與測試說明

## 使用邊界

此部署只供受邀教授檢視研究原型的工作流程、可用性與模型呈現。它不是醫療器材，也不能用於診斷、處方、分流或真實病人照護。

- 只可使用系統自動建立的 `示範個案 A/B`、已去識別化並獲授權的展示影像。
- 不可上傳真實病人影像、識別資料、封存 Blind Test 影像，或任何未取得外部測試核准的資料。
- Preview 資料庫、Fernet 金鑰及模型權重不得提交至版本庫、寄送給測試者或放在公開下載位置。

沒有自有網域、且只需短期教授測試時，改用 [無網域短期 HTTPS 預覽](./QUICK_PROFESSOR_PREVIEW_NO_DOMAIN.md)。該連結會每次更換，不能取代本文件的正式、穩定部署方式。

## 一次性準備

1. 準備一台具網域與 HTTPS 對外連線的伺服器，安裝 Docker Compose。
2. 將本專案與網域 DNS 指向該伺服器；開放 TCP 80、443，勿直接開放 8000。
3. 建立 `models/` 目錄，只放封版權重並以 `.env.professor-preview` 指定檔名。分類器必須是論文選定的 C-Arch-05 權重；在 handoff 紀錄其 SHA-256。
4. 複製 `.env.professor-preview.example` 為 `.env.professor-preview`，逐一替換網域、強密碼與新產生的 Fernet key。不要沿用開發環境的 `secret.key`。
5. 以 `docker compose -f docker-compose.professor-preview.yml up -d --build` 啟動。Caddy 會取得與續期 TLS 憑證。

## 上線驗收

1. 確認 `https://<網域>/healthz` 回應 `{"status":"ok"}`；這個端點不回傳模型或病人資訊。
2. 用 bootstrap 管理者登入後，建立教授帳號；不要共享管理者密碼。教授可用 `head_nurse` 身分檢視稽核與回饋，純流程測試可用 `nurse`。
3. 在「系統管理」建立或指派示範個案；護理師帳號只會看到指派給自己的個案。
4. 在「新增傷口評估」驗證：低信心／fallback 會出現黃色提醒，且不勾選人工覆核聲明無法標為「已覆核」。
5. 在「教授回饋」送出一筆測試意見，管理者或護理長確認可在資料庫稽核中追溯該事件。
6. 在登入失敗 8 次後確認暫時限制生效；測試完畢後重設教授帳號密碼。

## 測試任務建議

1. 以示範個案完成一筆影像分析，描述 AI 輸出、低信心提醒與人工覆核流程是否清楚。
2. 嘗試在未勾選人工覆核時標記「已覆核」並儲存，確認系統拒絕該操作。
3. 以教授回饋頁填寫易用性、臨床資訊清楚度與改善建議。

## 結束與清除

在教授測試結束後，匯出已去識別化的回饋與稽核摘要，再停止服務並刪除 `professor_preview_data/`。這會永久移除該次 preview 的帳號、示範紀錄與回饋；執行前應確認匯出已完成。絕不可刪除其他環境的臨床或研究資料庫。
