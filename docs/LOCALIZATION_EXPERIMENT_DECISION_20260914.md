# 實驗完成紀錄與模型採用判斷（2026-09-14）

## 本輪結論

D-Seg-03R 已完成 300 epochs 訓練；本輪進一步完成實際定位、裁切與速度對照。**新權重沒有全面勝過原 D-Seg-03，不應因 Mask mAP50 微幅上升就宣稱可落地能力提升。** 本輪不更新 App 權重，也不更動封存分類實驗。

這不是新的外部盲測；是對已用於模型開發的 FUSeg validation 做固定操作條件檢查。

## 實際完成的工作

1. 再確認原 FUSeg development 快照：train 771 張、validation 191 張。驗證集有 186 張含傷口、5 張無傷口，241 個 polygon 衍生的 GT 邊界框。
2. 鎖定新舊權重 SHA256、影像與標註清單、執行程式、授權證據與預先定義的評估條件。
3. 使用 GPU 完成 2 模型 × 2 個 NMS 設定的四輪推論，共 764 筆影像預測。各輪保留低 confidence 預測，再套用事先固定的 7 個 confidence 閾值，共 28 組 development 操作點、5,348 筆逐圖指標；這不是 28 次獨立實驗。
4. CPU 另測新模型在清單排序前 20 張驗證圖的速度，僅作裝置效能測量，不用來改動準確率結論。
5. 逐筆核對預測框、信心值、mask 檔雜湊、TP 配對唯一性與 IoU、TP/FP/FN 分母，以及結果彙總。新增評估器的 13 項合成資料測試通過。
6. 產生完整結果、逐圖明細、閾值曲線、單類物件配對矩陣、12 張最差裁切案例與書面報告。

新模型裁切成功由失敗轉成功 3 張，由成功轉失敗 7 張，淨減 4 張。這是同影像的描述性比較，沒有聲稱統計顯著，也不能據此證明 warmup 改動是因果。

歷史訓練報告的 Mask mAP50：D-Seg-03 約 90.07%、D-Seg-03R 約 90.32%。mAP 整合不同信心閾值下的偵測排序；本輪固定操作點與原始 mask 的裁切/像素評估是不同問題，不能互相替代。前述歷史 mAP 評估環境與批次設定並非完全相同，所以主比較採本輪一致的推論條件。

## 錯誤原因：目前證據能支持到哪裡

| 新模型 GT 尺度（bbox 佔原圖面積） | 命中 / 總數 | Recall | 漏偵測 |
|---|---:|---:|---:|
| small：<1% | 101/137 | 73.72% | 36 |
| medium：1% 至 <5% | 85/90 | 94.44% | 5 |
| large：≥5% | 14/14 | 100.00% | 0 |

- **36/41 個漏偵測屬小傷口**。這支持優先研究小目標處理，不支持單純認定訓練輪數不足。
- 最差裁切案例中，`fuseg__0079.png`、`fuseg__0456.png`、`fuseg__0730.png`、`fuseg__0816.png` 顯示小區域未得到預測。
- `fuseg__0349.png`、`fuseg__0548.png`、`fuseg__0192.png`、`fuseg__0046.png`、`fuseg__0971.png` 顯示多個 GT 區域只抓到部分位置；只扩大已偵測框的邊距，不一定能補到遠處漏掉的區域。
- 上述來自實際錯誤圖的視覺觀察，不是護理師診斷，也未證明標註有錯，**未擅自修改或刪除標註**。
- NMS=0.50 與 0.70 在此網格的 Recall 和裁切完整率相同；調整 NMS 並未解決主要漏偵測。
- 降低 confidence 可換取較高 Recall/裁切完整率，但會增加誤報；完整網格全部保留，未自動採用最漂亮的數字替換主結果。
- 僅有 5 張負樣本，不足以估計一般照護照片的穩定誤報率。

資料格式檢查也發現 `fuseg__0233.png` 的原始灰階標註含 32。已核對原資料轉換器採「像素 >0 為前景」，本輪沿用相同語義，191 張轉換後二值 mask 的 SHA256 均與原始建置清單一致；沒有修圖、補標或變更訓練標註。

## 實際速度與限制

- RTX 4060 Laptop GPU，新模型，NMS=0.70、收集 confidence≥0.01 的網格預測：平均 **47.83 ms/張**，中位數 46.73 ms，P95 56.72 ms，約 **20.91 FPS**。
- 同一 GPU 流程只計模型 forward：平均 33.71 ms/張。不得只拿這個數字當 App 全流程速度。
- CPU，新模型，主設定 confidence=0.10，前 20 張 validation：平均 **749.89 ms/張**，P95 823.99 ms，約 **1.33 FPS**。

三次合成影像暖機後測量，batch=1。主要壁鐘時間包含推論、NMS、mask 處理、回傳 CPU 與原圖尺度對齊；不含讀檔、指標分析、HTTP、分類器、RAG。GPU 與 CPU 的 confidence 和樣本數不同，不能當作完全等條件速度比。沒有做長時間負載或多人併發測試。

## 採用決策與下一個有效實驗

1. 不把 D-Seg-03R 自動升級為 App 預設模型。研究定位/裁切比較繼續保留 D-Seg-03 當參照；這不是臨床上線批准。
2. 已完成兩個低成本診斷：1024 全圖推論（小傷口 Recall +0.73 個百分點，但 F1 -1.24 個百分點）與四切片推論（小傷口 Recall +1.46 個百分點，但 F1 -8.58 個百分點、FP 27→84）。兩者都未達事前採用門檻，**沒有啟動另一輪 300 epochs**。目前不應把訓練輪數本身當作主要瓶頸。
3. 公開資料只有 Wound mask，不能計算七类傷口分類的 cascade 正確率。需獨立有同圖七類標籤的合格評估資料。
4. 真正跨資料來源泛化仍需一份未使用且來源/授權完整的獨立資料。不得將目前重複使用的 development validation 或已看過的 CO2Wounds 結果改稱全新盲測。
